# Sales and Inventory Management System

A desktop application developed using Python and MySQL to manage
products, inventory, sales, and sales reports.

## Features

- Add, update, and delete products
- Track product stock levels
- Detect insufficient stock before completing a sale
- Record sales and maintain sales history
- Display dashboard statistics
- Visualize best-selling products and daily revenue
- Generate date-based sales reports
- Export sales data to CSV

## Technologies

- Python
- MySQL
- Tkinter
- Matplotlib
- MySQL Connector for Python

## Requirements

- Python 3
- MySQL Server
- Required Python packages

## Setup

1. Install Python and MySQL.
2. Install the required Python packages.
3. Create the database and tables using the provided SQL schema.
4. Configure the database connection in `db.py`.
5. Run the application:

   `python main.py`

## Purpose

This project was developed to practice database management,
inventory tracking, sales operations, and business data visualization.
